# 🚀 React-DOM Interactive Learning & Quiz

Une plateforme web interactive conçue pour maîtriser les concepts fondamentaux de **React-DOM** à travers l'apprentissage théorique et l'auto-évaluation par quiz.

> **Accéder au projet en direct :** [👉 Tester l'application ici](https://learn-c5284.web.app/) 

---

## 📌 À propos du projet

Ce projet est une application pédagogique légère permettant aux développeurs de comprendre comment React interagit avec le DOM. Il combine des fiches de révision concises et des quiz interactifs pour valider les acquis instantanément. Il s'agit d'un site web statique généré avec Claude IA pour mieux comprendre cette notion de React-Dom et surtout savoir comment mettre en ligne un site Web statique avec Firebase Hosting.

### Points clés :
* **Apprentissage Interactif :** Modules structurés sur le rendu, la réconciliation et la manipulation du DOM.
* **Système de Quiz :** Évaluation en temps réel avec feedback immédiat sur les réponses.
* **Architecture Légère :** Développé en HTML5/CSS3 et JavaScript pur pour une performance optimale.

* **Déploiement Professionnel :** Hébergé sur **Firebase Hosting**, garantissant sécurité (SSL) et rapidité.

---

## 🛠 Technologies utilisées

* **Frontend :** HTML5, CSS3 (Design Responsive), JavaScript (ES6+).
* **Infrastructure :** [Firebase Hosting](https://firebase.google.com/docs/hosting) pour le déploiement et la mise en ligne.
* **Outils :** Firebase CLI.
