🎬 Guide d'utilisation

Regarder avec VLC

VLC Media Player est le lecteur le plus universel et recommandé. Disponible sur Windows, Mac, Linux, iOS et Android. Voici comment configurer Free-TV en 4 étapes.

✅ VLC est gratuit et open source. Téléchargez-le sur videolan.org avant de commencer.
1
Ouvrir le menu Média
Lance VLC puis clique sur Média dans la barre de menu en haut. Sur mobile, appuie sur les 3 points puis "Ouvrir un flux".
💡 Raccourci : Ctrl+N (Windows/Linux) ou Cmd+N (Mac)
2
Sélectionner "Ouvrir un flux réseau"
Dans le menu Média, clique sur "Ouvrir un flux réseau...". Une fenêtre de dialogue s'ouvre avec un champ URL.
💡 Tu peux aussi faire glisser l'URL directement dans la fenêtre VLC !
3
Coller l'URL M3U8
Copie l'URL du pays souhaité ci-dessus, puis colle-la dans le champ "Veuillez entrer une URL réseau" et clique sur Lire.
💡 Utilise la playlist mondiale pour accéder à tous les pays en même temps.
4
Naviguer dans les chaînes
VLC charge la playlist. Ouvre la Liste de lecture (Affichage → Liste de lecture) pour voir et naviguer entre toutes les chaînes disponibles.
💡 Utilise ↑ ↓ pour changer de chaîne pendant la lecture.
⚠️ Une chaîne ne fonctionne pas ? Les liens de streaming peuvent être temporairement indisponibles. La playlist est mise à jour automatiquement via GitHub Actions. Si un flux est cassé, vous pouvez le signaler sur GitHub Issues.
